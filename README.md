# DeskLink – Download

Remote Desktop für Freunde: Bildschirm teilen, Maus und Tastatur steuern, Bildschirm wechseln.

## ⬇️ Herunterladen

**[DeskLink für Windows herunterladen](https://github.com/RoboRobi2/desklink-download/releases/latest/download/DeskLink-Setup.exe)**

1. Datei öffnen. Windows zeigt eventuell „Der Computer wurde durch Windows geschützt“ → **Weitere Informationen** → **Trotzdem ausführen** (die App ist nicht signiert).
2. Beim ersten Start einen Namen wählen.
3. Freunde über ihren Namen hinzufügen.

DeskLink startet mit Windows im Tray und aktualisiert sich danach automatisch.

## Was kann DeskLink?

- Verbinden mit Freunden, jedes Mal mit Nachfrage – oder pro Freund „immer reinlassen“
- Bildschirm wechseln über das Symbol oben links oder **Strg+Alt+D** / **Strg+Alt+1…9**
- **Zeige-Modus** (Strg+Alt+P) und **Klick-Modus** (Strg+Alt+K): eigener Zeiger, die Maus des anderen bleibt
- Ton (ohne Discord, damit man sich im Call nicht selbst hört), Zwischenablage teilen
- Trennen mit **Strg+Alt+^**
- Du bekommst immer eine Meldung, wenn sich jemand mit deinem PC verbindet, und kannst jederzeit trennen (Tray → Alle trennen)
